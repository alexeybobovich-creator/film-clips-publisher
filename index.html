Film Clips Publisher

A private, internal publishing tool. It is not offered to the public.

Film Clips Publisher is a personal tool used only by its operator. It publishes short vertical video clips to the operator's own YouTube channel. The operator reviews each clip by hand. Only clips the operator approves are uploaded.

How it works

  1. The operator's own production pipeline renders short vertical clips.
  2. The operator reviews each clip and approves or rejects it.
  3. The tool uploads approved clips to the operator's YouTube channel through the YouTube Data API. It then checks each upload's processing status.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

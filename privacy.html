Privacy Policy

Effective October 19, 2026

Film Clips Publisher ("the tool") is a private, internal tool. Its operator uses it to publish videos to the operator's own YouTube channel. The tool has no other users and is not offered to the public. This policy explains what data the tool accesses and how that data is used, stored, shared, and deleted.

YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to the YouTube Terms of Service. Google's own data practices are described in the Google Privacy Policy.

What data the tool accesses

The tool asks for two Google OAuth permissions:

  • youtube.upload: to upload videos the operator has approved to the operator's channel.
  • youtube.readonly: to read the channel's ID and title. The tool also reads the upload, processing, and privacy status of the videos it has uploaded.

The tool does not read or change any other videos, comments, subscribers, playlists, or analytics. It does not access other Google services.

How the data is used

The data is used only to publish the operator's own approved videos and to confirm that each upload succeeded. It is not used for advertising, profiling, or any other purpose. It is not used to train machine-learning models.

How the data is stored

  • OAuth tokens are kept on the operator's own computer or server, in a file that only the operator's account can read. They are never committed to source control.
  • The tool keeps a publication record for each upload: the YouTube video ID, its URL, its status, and the upload time. These records are stored in the operator's private database.
  • The tool sets no cookies and uses no analytics or tracking services.

Sharing

Data obtained through YouTube API Services is not sold or shared with third parties. It is not disclosed to anyone except Google, as part of using the API.

Retention and deletion

  • OAuth tokens are kept until access is revoked. Once access is revoked, the tokens are deleted.
  • Publication records are kept for as long as the operator needs them to manage the channel. The operator can delete them at any time.
  • You can revoke the tool's access at any time on the Google security settings page.
  • To ask for stored data to be deleted, email the address below. Deletion is completed within 7 days.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
